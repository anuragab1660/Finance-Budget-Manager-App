# 💰 SmartBudget – Personal Finance Manager (Flutter)

SmartBudget is a modern cross-platform Finance & Budget Manager mobile application built using Flutter.  
It helps users track income, manage expenses, analyze spending patterns, and maintain financial discipline through real-time analytics and visual insights.

---

## 🚀 Features

### 🔐 Authentication
- Firebase Email/Password Login
- Secure user session handling
- Logout & profile management

### 💵 Expense & Income Management
- Add / Edit / Delete transactions
- Categorize expenses (Food, Travel, Bills, Shopping, etc.)
- Add notes & date selection
- Recurring transaction support

### 📊 Analytics Dashboard
- Monthly expense summary
- Income vs Expense comparison
- Category-wise spending breakdown
- Interactive charts (Pie + Bar Graph)

### 💳 Budget Planning
- Set monthly budget limit
- Real-time budget tracking
- Overspending alerts

### 📁 Data Export
- Export transactions to PDF
- Export data to CSV file

### 🌍 Multi-Currency Support
- INR, USD, EUR support
- Currency selection option

---

## 🧠 Tech Stack

### 📱 Frontend
- Flutter (Dart)
- Provider / Riverpod (State Management)
- Clean Architecture
- MVVM Pattern

### 🔥 Backend
- Firebase Authentication
- Firebase Firestore Database
- Firebase Cloud Messaging (Notifications)

### 📊 Charts & Visualization
- fl_chart package
- Syncfusion Charts (optional)

### 🧪 Testing
- Unit Testing
- Widget Testing

---

## 🏗 Architecture

This project follows **Clean Architecture + MVVM pattern**:

Presentation Layer → ViewModel → Repository → Data Source (Firebase)

- Separation of concerns
- Scalable code structure
- Easy to maintain & test
